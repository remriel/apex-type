The alpine trees and rocks are from [Kenney Nature Kit](https://kenney.nl/assets/nature-kit), licensed CC0. The original Kenney license text is included beside the models. The finished car roster uses the classic models credited above.

The alpine panorama and asphalt texture were generated for this project with the built-in image-generation tool and processed into WebP assets. The track ribbon, markings, minimap, lighting, and UI icons are runtime geometry or interface code.

Typography: Barlow Condensed, DM Sans, and Space Mono, served through Google Fonts. Browser fallback fonts remain available if the font service is unavailable.
